# 🎮 RS Games Portal (430+ Free Web Games)

एक बेहतरीन, आधुनिक और आकर्षक **RS Games Portal** वेबसाइट जिसमें **430+ HTML5 & JavaScript Games** जोड़ी गई हैं।

---

## 🚀 वेबसाइट कैसे चलाएं (How to Run)

### तरीका 1: एक क्लिक में चलाएं (Easiest)
ज़िप एक्सट्रैक्ट करने के बाद बस **`start-server.bat`** फ़ाइल पर डबल-क्लिक करें! वेबसाइट अपने-आप ब्राउज़र में खुल जाएगी।

### तरीका 2: Node.js सर्वर (Recommended)
टर्मिनल / कमांड प्रॉम्प्ट में इस फ़ोल्डर में जाएं और चलाएं:
```bash
node server.js
```
इसके बाद अपने ब्राउज़र में खोलें:
👉 **`http://localhost:3000`**

### तरीका 3: सीधे ब्राउज़र में खोलना (Direct File Open)
आप `index.html` फ़ाइल पर डबल-क्लिक करके भी सीधे Google Chrome, Edge, या Firefox में चला सकते हैं!
